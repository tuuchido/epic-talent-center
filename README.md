# EPIC Talent Center – Website v2

Website landing page cho EPIC, phong cách nghệ thuật – sáng tạo – dễ thương – hiện đại.

## Cấu trúc
- index.html
- style.css
- script.js
- assets/
└── logo1A.png

## GitHub Pages
Upload `index.html`, `style.css`, `script.js` và thư mục `assets` vào thư mục gốc repository. Sau đó Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

## Lưu ý
Ảnh, giáo viên, lịch học, học phí và thông tin liên hệ đang là placeholder. Form hiện là demo và lưu đăng ký vào localStorage của trình duyệt; cần nối Google Forms/Google Sheets/Formspree/backend để nhận dữ liệu thật.
